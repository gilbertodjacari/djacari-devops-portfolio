# Portfólio — Gilberto Duarte Djacari

Portfólio pessoal em HTML/CSS/JS puro (sem dependências de build), pronto para publicar via GitHub Pages.

## Ficheiros

- `index.html` — página única com todo o portfólio (Sobre, Experiência, Competências, Projetos, Formação, Contacto).

## Publicar no GitHub Pages

1. Cria um repositório público no GitHub.
   - Para ficar em `https://gilbertodjacari.github.io/`, o repositório deve chamar-se exatamente `gilbertodjacari.github.io`.
   - Qualquer outro nome funciona também, mas o link fica `https://gilbertodjacari.github.io/<nome-do-repositorio>/`.
2. Faz upload de `index.html` (e este `README.md`, opcional) para a raiz do repositório.
3. Vai a **Settings → Pages** → em "Build and deployment", escolhe **Source: Deploy from a branch**, **Branch: main**, pasta **/ (root)**. Guarda.
4. Aguarda 1–3 minutos. O link fica disponível no topo da própria página de Settings → Pages.

## Domínio próprio (opcional)

Em Settings → Pages, campo "Custom domain", escreve `devdjacari.com`. No DNS do domínio, cria um registo CNAME apontando para `gilbertodjacari.github.io`.
